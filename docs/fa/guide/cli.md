# خط فرمان

```bash
export DOCLIB_ROOT=~/archive
python3 ~/archive/doclib.py <command> [args]
```

## افزودن

| دستور | کار |
|---|---|
| `add <path> [-c COLL]` | ایندکس فایل یا پوشهٔ داخل مجموعه — `raw/` برای منابع، `wiki/` برای صفحه‌ها |
| `rm <file_id>` | حذف از ایندکس؛ فایل در `raw/` دست‌نخورده می‌ماند |
| `reindex [-c COLL]` | استخراج دوبارهٔ همهٔ فایل‌ها از `raw/` |

## جستجو

| دستور | کار |
|---|---|
| `search <query> [-c] [-f NAME] [-n LIMIT]` | جستجوی FTS5 با AND و تطبیق پیشوندی |
| `list [-c COLL]` | فایل‌ها با تعداد تکه |
| `show <file_id>` | همهٔ تکه‌های یک فایل، به ترتیب |
| `stats` | آمار هر مجموعه |
| `collections` | مجموعه‌ها با توضیح دامنه |

## ویکی

| دستور | کار |
|---|---|
| `lint [-c COLL]` | شش بررسی ساختاری، خروج ۱ اگر ایراد باشد |
| `graph [-c COLL]` | درجهٔ ورودی/خروجی هر صفحه |
| `links <page> -c COLL` | هر دو جهت لینک برای یک صفحه |

## منبع در حال مطالعه

| دستور | کار |
|---|---|
| `ur-new <slug> --title T -c COLL` | ساخت صفحهٔ کتاب در حال مطالعه |
| `ur-add <slug> -p N -q TEXT -c COLL` | افزودن یک نقل‌قول با شماره صفحه |
| `ur-list` | فهرست کتاب‌های در حال مطالعه |

## کد خروج

`0` موفق یا جستجوی بی‌نتیجه · `1` آرگومان غلط، فایل نبود، ایراد lint.
